1. Accessibility Access

Designed to assist users with disabilities by reading screen content and performing automated interface actions. Legitimate screen readers rely on it; abusive apps can read OTPs or perform unauthorised taps.

2. Notification Access

Allows companion apps (such as smartwatches or call-screeners) to display or manage notifications. If abused, an app could silently read incoming banking alerts and OTPs.

3. Display Over Other Apps

Used legitimately by chat bubbles, floating timers, and screen-dimming tools. Maliciously, overlays can hide warning prompts or mimic legitimate login screens.

4. Install Unknown Apps

Permits a browser, file manager, or messaging app to install APK packages outside an official app store. Scammers often send APK files over chat pretending to be bank updates or e-challans.
