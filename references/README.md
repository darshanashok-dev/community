# Reference Documents

This project implements the approved academic community project specification documented in:

1. `synopsis_updated_v5_privacy_security.docx` (primary technical specification)
2. `community_project_ppt_updated.pptx` (supporting presentation context)

Key referenced advisories and technical standards from the synopsis:
- Indian Cyber Crime Coordination Centre (I4C), *Digital Arrest Scam*, Advisory TAU/ADV/003 (6 Mar 2025), `cybercrime.gov.in`
- Indian Computer Emergency Response Team (CERT-In), *Preventing Online Scams*, Advisory CIAD-2024-0050 (24 Oct 2024), `cert-in.org.in`
- Google Safe Browsing API v5 (`hashes.search` four-byte SHA-256 hash-prefix lookup) and Terms of Service
- ICANN Registration Data Access Protocol (RDAP)
- OWASP Logging Cheat Sheet
- W3C Web Content Accessibility Guidelines (WCAG) 2.2 AA
